# Operations runbooks

Short, task-focused guides for a single-host lab install:

- [Install](install.md) — fresh setup and first login
- [Upgrade](upgrade.md) — back up, upgrade, verify, and roll back
- [Backup and restore](backup-restore.md) — protect and restore the SQLite database
- [Incident triage](incident-triage.md) — handle alerts, blocks, kill switch, and rollback

These are operational aids, not a production security audit. Keep the service on localhost unless you have completed a security review.
