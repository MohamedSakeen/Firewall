# Code of Conduct

## Our goal

This project should be a safe, useful place for people to learn, build, and contribute to host security tooling.

## Expected behavior

- Be respectful and constructive.
- Assume good intent and ask questions before judging.
- Give specific, actionable feedback.
- Respect different experience levels.
- Keep discussions focused on the project.

## Unacceptable behavior

- Harassment, threats, insults, or personal attacks
- Publishing someone else's private information
- Sexist, racist, homophobic, transphobic, or similar discriminatory language
- Trolling or deliberately disruptive behavior
- Requesting help with unauthorized attacks or real-world harm

## Scope

This applies in issues, pull requests, discussions, code reviews, and other project spaces.

## Enforcement

Maintainers may edit or remove content, warn contributors, or block access when needed. Reports should be sent privately to the maintainers. Reports will be handled with discretion.
